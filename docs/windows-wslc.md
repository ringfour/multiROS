# Windows with WSLC

The current WSLC setup, adapter limits and resource settings are in
[Platforms → Windows PowerShell and WSLC](platforms.md#windows-powershell-and-wslc).

For the tested WSL2/Docker Desktop workflow, use
[Platforms → WSL2 with Docker Desktop](platforms.md#wsl2-with-docker-desktop).
